# Filosofia de monetização — Bota Preço

> A experiência do usuário sempre tem prioridade sobre a exibição de anúncios.

- Anúncios financiam a ferramenta; **nunca** atrapalham o uso.
- O Bota Preço não deve parecer um site criado para mostrar publicidade.
- Locais permitidos: Home, área educacional (Aprenda), páginas institucionais.
- **Proibido** interromper Rapidin e Completão com anúncios no meio do fluxo
  (exceção: slot discreto no Completão mid-flow, já existente, revisável).
- Resultado e relatório **sempre gratuitos** — sem paywall, sem desbloqueio.
