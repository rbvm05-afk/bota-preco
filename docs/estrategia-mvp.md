# Diretriz Estratégica — MVP Bota Preço

## Decisão

O Completão cresceu para um segundo produto. Desenvolver os dois em paralelo atrasa o lançamento.

**MVP = plataforma sólida + Rapidin impecável.**

## Completão

- Não cancelado — apenas fora do MVP.
- Sem novas funcionalidades, UX ou componentes específicos.
- Arquitetura preservada (`Calculation`, chapters, `parentId`, Continuity).
- UI pública: “Em breve”.

## Foco

Toda decisão responde: **“Isso torna o Rapidin melhor?”**

Preferimos um Rapidin nota 10 a um Rapidin 8 + Completão 6.

## Roadmap

| Versão | Foco |
|--------|------|
| 2.8.x | Lapidar Rapidin (UX, textos, a11y, performance, cálculos) |
| 2.9.x | Plataforma (Aprenda, SEO, institucionais, AdSense) |
| 3.0.x | Supabase, login, sync, histórico em nuvem |
| depois | Retomada oficial do Completão |
